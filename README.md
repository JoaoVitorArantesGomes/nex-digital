## 📖 Sobre o projeto

**Nex Digital** é o site institucional de uma agência de criação de sites voltada para pequenos negócios — barbearias, academias, restaurantes e profissionais liberais.

O projeto foi desenvolvido do zero, com foco em **design premium**, **responsividade** e **código limpo e reutilizável**. Além da página principal da agência, inclui **três sites de demonstração completos**, cada um com identidade própria dentro do mesmo sistema visual.

---

## ✨ Destaques

- 🎨 **Identidade visual premium** — tema escuro (preto + dourado champagne) com detalhes angulares
- 📱 **100% responsivo** — adaptado para desktop, tablet e celular
- ⚡ **Código reutilizável** — CSS e JS compartilhados entre todas as páginas
- 🧩 **Componentes genéricos** — lista de preços, galeria, grade de planos e horários reaproveitáveis
- 🔧 **Contato centralizado** — WhatsApp, Instagram e e-mail configurados num único ponto do código
- 🖼️ **Galerias com lazy loading** — imagens otimizadas para performance

## 🗂️ Estrutura

```
nex-digital/
├── index.html          # Página principal da agência
├── style.css           # Estilos compartilhados (tema, componentes, responsivo)
├── script.js           # Interações + configuração de contato centralizada
├── README.md
├── img/                 # Fotos usadas nas demos, organizadas por nicho
│   ├── barbearia/           hero.jpg + foto1–4.jpg
│   └── academia/            hero.jpg + foto1–3.jpg
└── demos/               # Sites de demonstração por nicho
    ├── barbearia.html      → Studio Navalha
    ├── academia.html       → Forma Fitness
    └── restaurante.html    → Cantina Rossi
```
